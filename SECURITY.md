# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue**.

Instead, report it privately by opening a [private security advisory](../../security/advisories/new)
on GitHub, or email **daksh1403@users.noreply.github.com** with details and
steps to reproduce.

Please include:
- A description of the issue and its potential impact
- Steps to reproduce
- Affected versions / commit

I will acknowledge reports within 48 hours and aim to issue a fix or mitigation
as soon as feasible. Coordinated disclosure is appreciated.

## Scope

This policy covers the latest release on the `main` branch. Please test against
a current checkout before reporting.
