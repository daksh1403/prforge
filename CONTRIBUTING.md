# Contributing

Thanks for your interest in contributing! This project welcomes contributions of all kinds — bug reports, fixes, features, docs and ideas.

## Getting Started

1. **Fork** the repository and clone your fork.
2. Create a feature branch: `git checkout -b feat/my-change`.
3. Make your changes, keeping commits focused.
4. Open a **Pull Request** against `main` and fill in the template.

## Guidelines

- **Code** — match the existing style, keep diffs small and reviewable.
- **Commits** — use clear, conventional messages (e.g. `feat: …`, `fix: …`, `docs: …`).
- **Tests** — add or update tests for any behavioural change; ensure the suite passes locally before pushing.
- **Docs** — update the README and relevant docs when behaviour changes.

## Reporting Issues

- Search existing issues before opening a new one.
- Use the issue templates and include steps to reproduce, expected vs. actual behaviour, and environment details.

## Code of Conduct

By participating you agree to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). Be kind and constructive.
